Boba Game Time

A playful, paper-textured design system for a server of casual party games. Sticker outlines, bouncy springs, milky beige.

Color

Warm milky beige base, deep brown ink, peach as primary accent and jade as secondary. Per-game accents layer over the neutrals — chrome stays calm, the game does the singing.

Cards & surfaces

Paper, with subtle grain, soft drop-shadow, and a slight rotation when stacked. Hover lifts and straightens. Three flavors: .paper (raised), .paper.sticker (offset shadow), and the game-card in-hand presentation.

Raised paper

Soft drop-shadow, no outline rotation. Used for content blocks, score boards, modals.

Sticker paper

Hard offset shadow, slight tilt. Used for "fun" surfaces — turn status, found cards, results banners.

Hand of cards

Five cards stacked with rotation. Hover to peek (lifts and straightens).

Buttons

All buttons have the same chunky 2px outline and a colored offset shadow. On hover, the button shifts up-left by 1px (extending the shadow). On press, it slams into its shadow.

Scout cards · color ramp

Scout cards carry two numbers (one at each end — the card flips). The card's value drives the color, and the ramp is hue-adjacent so neighboring values blend visually. The bottom half is the flip value — solid color on top, 50% alpha on the bottom over the card body.

Single card anatomy

Top number = primary value (drives the solid top half). Bottom number = flip value (drives the tinted bottom half). Big numeral centered for table readability; small numerals at corners for in-hand fans.

All numerals use a white fill with a 2.5–4px dark stroke (-webkit-text-stroke + paint-order: stroke fill). The stroke makes white pass contrast uniformly across every ramp color — including #7 yellow — and reinforces the sticker aesthetic. No yellow special-case needed.

Flip · interactive

Click any card to flip it 180°. The numeral that was upside-down at the bottom is now reading at the top — that's the "flipped" value you'd commit to playing.

Light vs. dark

In light mode the bottom half tints the cream card body warm. In dark mode it darkens against deep brown — bottom values stay distinguishable but read more muted, which is fine; the top half (the value you played) remains the dominant signal.
